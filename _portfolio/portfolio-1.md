This project provides the Python implementation for the **Parametric Tensor Train Kernel (PTTK) method**.

It is the code associated with the 2025 *SIAM Journal on Matrix Analysis and Applications* paper, "Parametric kernel low-rank approximations using tensor train decomposition".
